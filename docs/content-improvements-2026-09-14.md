# 콘텐츠 보완 기록 — 2026-09-14

## 요청과 범위

AdSense의 ‘가치가 별로 없는 콘텐츠’ 안내에 대응해 서비스의 실제 이용 가치를 보강했다. 이 작업이 승인을 보장하거나 Google의 개별 판정 원인을 확정하는 것은 아니다. AdSense 검토 요청은 이 작업에서 제출하지 않는다.

## 반영 내용

- 한국어/영어 테마별 퍼즐 3개: `/collections/mountain-lake`, `/collections/sunlit-forest`, `/collections/city-skyline`. 영어는 `/en` 접두사.
- 각 사진을 눈으로 확인한 뒤 선정 이유, 구체적인 풀이 단서, 혼동 지점, 다음 도전을 작성했다. 촬영 장소나 계절을 추정해 이름 붙이지 않았다.
- 해설과 게임은 동일한 4:3 이미지 영역을 사용한다. 개별 페이지의 게임은 사진 검색 API 없이 시작할 수 있지만 Unsplash 이미지 요청은 필요하다.
- 가이드 4개: 첫 20피스 교환 실습, 실제 사진 선택 사례, 20/48/120피스 격자 비교, 막힌 상황별 풀이. 모두 한영 제공.
- 영어 Privacy/Terms 번역 및 메뉴·본문 링크 보완. 정보 페이지의 본문 언어와 브라우저 문서 언어 동기화.
- 전체 28개 페이지를 사이트맵과 한영 대체 URL에 등록. 본문은 서버에서 HTML로 렌더링한다.
- 기존 원격 커밋 `31e51d2`의 Kakao AdFit 기본 비활성화와 광고 단위 수정을 fast-forward로 보존했다.

## 확인

- `npm run lint`, `npm run build` (vinext), `npx next build` 통과.
- `node scripts/verify-content.mjs`로 28개 페이지의 HTTP 응답, 본문 h1, 언어, canonical, 내부 링크/앵커 및 알 수 없는 경로의 404 확인.
- 브라우저: 교환 실습 선택/완성, 한영 가이드 전환, 20피스 게임 시작, 12피스 직소에서 한 조각 배치 후 잔여 11개 확인.
- 테마 간 이동 시 사진·추천 조각 수·게임 진행 초기화 확인.
- 모바일 영어 컬렉션에서 가로 넘침 없음 확인.

## 다음 운영 단계

운영 배포 확인 후 AdSense 사이트 화면에서 개선한 내용을 확인하고 검토 요청을 한 번 제출한다. 추가 가이드는 실제 이용 문제와 플레이 사례를 바탕으로 작성하며, 글 수·글자 수를 채우기 위한 페이지를 만들지 않는다. 진행 저장 기능은 아직 없으며 안내에 이 점을 명시했다.
